              What we need — any one works

              1. Carrier billing exports — DHL eCommerce, UPS, USPS · last 3–6 months
              2. Shipment export from NetSuite or the Randolph WMS
              3. Monthly carrier statements (PDF) for the same period

              Fields: ship date, tracking #, carrier, service, origin ZIP, destination ZIP, actual weight, dimensions or billed weight, zone, total charge, surcharge lines.

              No customer names or street addresses needed

              Last season's cookie direct-ship statements are welcome too if they're easy to pull.

              Pulling it from NetSuite (~15 minutes)

              1. Reports → Saved Searches → All Saved Searches → New · type Transaction
              2. Criteria: Type = Item Fulfillment · Date = last 6 months (or the full Aug–Jul year) · Main Line = Yes
              3. Results: Date · Document Number · Created From · Ship Via · Shipping Carrier · Tracking Numbers · Ship Zip · Ship State · Ship City · Shipping Cost · Package Weight · Package L/W/H · Location
              4. Save & Run → Export – CSV
              5. Leave Name and Address 1 off. Send under the NDA.

              If a label app (ShipStation, Pacejet, EasyPost…) prints your labels, its shipment export is faster and already includes weights and dimensions.
